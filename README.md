- **Your footage never leaves your machine.** No waiting in cloud server queues. No worrying about unpublished podcast leaks, private gameplay footage, or copyright strikes from cloud caching.
- Runs on your local GPU/CPU with **zero video length limits** and **no monthly credit caps**. Clip 5-hour livestreams or 20-minute interviews with equal ease.

### 3. 🔴 Live Studio: Real-Time Livestream AI Clipper (OBS Studio, Twitch, Kick, YouTube)

### 4. 🤖 Built-in Clippy AI Assistant (Instant Co-Pilot)
- Need help clipping live streams or burning text overlays? Click the sleek, flush edge toggle arrow (`‹`) pinned on the right edge.
- **Deep-Link Auto Navigation**: Ask Clippy *"How do I clip live streams?"* and it will automatically navigate to Live Studio (`/live`) and guide you step-by-step.
- **Smart Model Routing**: Benchmarks your local Ollama models (`qwen2.5:3b`, `qwen3:4b`, `llama3.2`, `mistral`) and dynamically pairs with your fastest local engine.

### 5. 🎙️ Smart Solo & Dual Split Screen (No Half-Body Glitches)
- **True 2-Person Podcast Layout**: Automatically identifies Speaker 1 (top) and Speaker 2 (bottom) with centered headroom and natural torso margins.
- **Smart Solo Speaker Fallback**: Unlike naive competitors that blindly chop single speakers into weird face-top / wrist-bottom cuts, Clipify AI verifies spatial cluster separation (`sep >= 0.18`). If only one person is on screen, it automatically falls back to full-height 9:16 solo vertical framing!
- **Interactive Draggable Divider**: Customize the split ratio freely in Beta Lab from **Top 30% / Bottom 70%** to **Top 70% / Bottom 30%**.

### 6. ✨ Anti-Burst Lanczos Upscaler (Pristine 1080p Quality)
- **No blurry, macroblocked re-encodes.**
- **Lossless Subclip Trimming**: Cuts raw subclips using lossless x264 (`-crf 0`), completely eliminating generational degradation before framing begins.
- **4 Precision Profiles**:
  - `Ultra`: Lanczos scaling + unsharp mask + CRF 17 + 10 Mbps (Maximum crispness, anti-burst).
  - `High`: Lanczos scaling + subtle sharpening + CRF 18 + 8 Mbps (Recommended balance).
  - `Balanced`: Standard 1080p high-speed encoding + CRF 22 + 5 Mbps.
  - `Fast`: Fast bilinear preview + CRF 25.

- Word-by-word highlighted karaoke subtitles with pop animations, customizable accent colors (Gold Yellow, Lime Green, Cyan Sky, Coral Red, Pink Lavender).
- Creator fonts pre-loaded: **Montserrat**, **The Bold Font**, **Komika Axis**, and **Anton**.
- 100% frame-accurate audio sync via WhisperX word-level alignment.

### 8. 🗣️ Faceless Narration Studio (Kokoro Neural Speech)

## 🚀 Quick Start Guide

### Method 1: Windows 1-Click Installer (Recommended)

1. Download **[`Clipify.AI.Setup.4.0.11.exe`](https://github.com/sherlock-dev-ai/Clipify-AI-Video-Clipper-FREE/releases/download/v4.0.11/Clipify.AI.Setup.4.0.11.exe)** (331.8 MB).
2. Run the installer. It will automatically:
   - Configure embedded Python 3.11 runtime.
   - Install required FFmpeg binaries, WhisperX, and PyTorch.
   - Detect or pull local Ollama models (`qwen2.5:3b`).
   - Create desktop and Start Menu shortcuts.
3. Launch **Clipify AI** from your desktop and start creating viral shorts!

---

### Method 2: Manual Developer Setup (From Source)

```powershell
# 1. Clone the repository
git clone https://github.com/sherlock-dev-ai/Clipify-AI-Video-Clipper-FREE.git
cd Clipify-AI-Video-Clipper-FREE

# 2. Create and activate a Python 3.11 virtual environment
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Install runtime dependencies
pip install -r requirements-runtime.txt

# 4. Pull your preferred Ollama model
ollama pull qwen2.5:3b

# 5. Launch Clipify AI Studio
python app.py
```

Open `http://127.0.0.1:5000` in your web browser.
