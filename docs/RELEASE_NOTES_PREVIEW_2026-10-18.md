Clipify AI has a vertical clipping workflow with timed captions and a separate script-led narration workflow. Qwen review can use a configured local Ollama service. Runtime and selected model downloads depend on setup choices and may require several gigabytes.

This is a preview build for evaluation. Minimum Windows version, hardware requirements, and general-release compatibility have not been certified. Review installer prompts and the website before setup.

The installer is not digitally signed, so Windows may display an unknown-publisher prompt.
